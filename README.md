Number Guessing Game (Upgraded Version)
Ein interaktives Zahlen-Raten-Spiel in Python! Ich habe meine erste Version genommen und sie mit neuen Features verbessert.

Was in dieser Version neu & verbessert ist:
Schwierigkeitsgrade: Modus-Auswahl (z. B. Leicht, Mittel, Schwer) mit unterschiedlicher Anzahl an Versuchen.
Fehlerabfangung: Das Programm stürzt nicht mehr ab, wenn man versehentlich Text statt einer Zahl eingibt.
Tipps & Feedback: Das Spiel zeigt an, ob die gesuchte Zahl höher oder niedriger ist, und gibt Hinweise, wie nah man dran ist.
Highscore & Versuche-Zähler: Es wird gezählt, wie viele Versuche benötigt wurden.

🛠️ Was ich dabei in Python gelernt habe
Schleifen (while)
Zufallszahlen: Wie man Python eine geheime Zahl generieren lässt.
Erweiterte Logik (if / elif / else): Für Feedback nach jedem Versuch.
